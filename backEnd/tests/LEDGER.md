# Test ledger

Every test file, the invariant it protects, and the release that introduced it
(BUILD_PLAN section 0, rule 5). Changing a behavior means changing its test in the same
change, with the reason stated in the commit message and in the Notes column here.

Run everything from `backEnd/` with `uv run pytest -q`. `-m "not legacy"` runs only the
basis suite; `-m "not slow"` skips the subprocess-based checks; `-m integration` runs the
tests that need Docker (a `pgvector/pgvector:pg16` container via testcontainers). The
Temporal-backed ones (S2) also start a Temporal dev server with
`WorkflowEnvironment.start_local()`: the `temporal` CLI when it is on `PATH`, otherwise
the SDK downloads it.
