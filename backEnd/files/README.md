# Reference documents (not tracked)

This directory holds the source PDFs used to build the reference corpus:
IRS Publication 946, Publication 527, Publication 5653 (Cost Segregation
Audit Techniques Guide), Rev. Proc. 87-56, and the RSMeans 2020 Building and
Residential cost books. They are not tracked in git: the IRS documents are
public and available from irs.gov, and the RSMeans books are commercial
publications that must not be redistributed from a public repository.

Built indexes are stored in the `basis-evidence-layer-prod` bucket; see
`docs/review_2026-10-15/INFRA_NOTES.md`.
