# Provider logos

Local SVG assets identify the service or model author; they do not indicate health or endorsement. Status dots and labels remain separate. Logos retain their proportions and source colors. No logo request goes to a third-party host at runtime.

- OpenAI, Meta, Claude, Replicate, Azure: `@lobehub/icons-static-svg` **1.101.0**, [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT (license included).
- FastAPI, PostgreSQL, Temporal, Firebase: `simple-icons` **16.36.0**, [Simple Icons](https://github.com/simple-icons/simple-icons), CC0-1.0 (license included).
- Reviewed [OpenAI brand guidance](https://openai.com/brand/) and [Meta brand guidance](https://www.meta.com/brand/resources/meta/company-brand/). Brand marks belong to their respective owners. OpenAI's Blossom identifies the GPT API here; this is not a ChatGPT consumer-app integration.
- Meta identifies SAM 3 and Mask2Former. Replicate identifies the optional hosting provider separately. Unbranded internal processing steps are not assigned an inferred vendor.
